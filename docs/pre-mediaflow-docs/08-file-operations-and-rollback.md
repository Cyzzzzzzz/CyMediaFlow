# MediaFlow 文件操作、冲突与回滚规格

> 文档编号：MF-FILE-001  
> 风险等级：最高

## 1. 安全不变量

以下规则不得被配置关闭：

1. 源路径和目标路径必须位于授权根目录；
2. 操作计划中的目标路径必须唯一；
3. 默认不得覆盖现有文件；
4. 跨设备移动只有在复制校验成功后才能删除源；
5. 未知文件不得自动删除；
6. 每个改变文件系统的操作必须有持久化记录；
7. 计划执行时不得重新推断目标名称；
8. 状态不确定时停止并要求恢复，不盲目重试。

## 2. 文件系统端口

```python
class FileSystemPort(Protocol):
    def stat(self, path: Path) -> FileStat: ...
    def exists(self, path: Path) -> bool: ...
    def realpath(self, path: Path) -> Path: ...
    def mkdir(self, path: Path, parents: bool, exist_ok: bool) -> None: ...
    def rename(self, source: Path, destination: Path) -> None: ...
    def copy_file(self, source: Path, destination: Path, progress: ProgressCb) -> None: ...
    def hardlink(self, source: Path, destination: Path) -> None: ...
    def symlink(self, source: Path, destination: Path) -> None: ...
    def unlink(self, path: Path) -> None: ...
    def rmdir(self, path: Path) -> None: ...
    def hash(self, path: Path, mode: HashMode) -> str: ...
    def free_space(self, path: Path) -> int: ...
```

业务层不直接调用 `os`、`shutil`。

## 3. 操作计划

### 3.1 计划生成

OperationPlan 包含：

- 任务与计划版本；
- 源快照；
- 目标路径；
- 操作类型；
- 预期文件大小和快速哈希；
- 冲突状态；
- 执行顺序；
- 目标目录创建项；
- 可选空目录清理项。

计划生成后计算规范 JSON 的 SHA-256。执行请求必须携带计划 ID 和哈希。

### 3.2 计划过期

以下变化使计划失效：

- 源文件大小或 mtime 变化；
- 解析结果修改；
- 条目或映射修改；
- 命名模板修改；
- 目标媒体库修改；
- 目标路径出现新文件；
- 计划超过可配置有效期。

## 4. 预检

执行前按顺序检查：

1. 计划是当前 active plan；
2. 计划状态为 `valid`；
3. 任务状态为 `READY`；
4. 源文件存在且快照一致；
5. 源真实路径位于允许根；
6. 目标真实父路径位于目标根；
7. 目标文件不存在，或有已确认冲突策略；
8. 所有目标路径无大小写或 Unicode 冲突；
9. 目标目录可写；
10. 复制需要的总空间充足，预留安全比例；
11. 硬链接源目标设备相同；
12. 计划没有重复目标；
13. 文件未被其他任务锁定。

预检结果持久化并在前端展示。

## 5. 路径安全

### 5.1 规范化

- 转换绝对路径；
- 解析 `.` 与 `..`；
- 获取真实路径；
- 检查大小写敏感性；
- Unicode NFC；
- 拒绝 NUL 和控制字符；
- 目标文件名不得为 `.` 或 `..`。

### 5.2 根目录验证

使用路径组件比较，不使用字符串 `startswith`：

```python
resolved.relative_to(allowed_root_resolved)
```

符号链接可能跳出挂载根，必须对现有父路径使用 `realpath` 检查。

### 5.3 源目标嵌套

禁止：

- 目标目录位于待整理目录内部且会被再次扫描；
- 源目录位于目标目录内部并形成递归；
- 数据/配置目录被配置为媒体目录。

## 6. 命名合法化

### 6.1 默认替换

| 字符 | 替换 |
|---|---|
| `:` | ` -` |
| `/`、`\` | `-` |
| `?`、`*` | 删除 |
| `"` | `'` |
| `|` | `-` |
| `<`、`>` | `(`、`)` 或删除 |

清理后：

- 合并空格；
- 去除尾部点和空格；
- 检测 Windows 保留名；
- 文件名为空时失败；
- 保留扩展名和季集标记。

### 6.2 大小写冲突

在大小写不敏感文件系统上，`Show.mkv` 与 `show.mkv` 冲突。系统启动或测试路径时探测文件系统特性，计划中按目标文件系统规则比较。

### 6.3 Unicode 冲突

以 NFC 形式比较目标名，避免视觉相同但编码不同的重复文件。

## 7. 操作实现

### 7.1 同设备移动

优先使用原子 `rename`：

1. 创建 `PENDING` 记录；
2. 再次确认目标不存在；
3. 调用 rename；
4. stat 目标；
5. 更新 MediaFile.current_path；
6. 标记记录成功。

不得使用会覆盖目标的 API 语义，除非冲突策略显式允许且另有备份流程。MVP 不支持覆盖。

### 7.2 跨设备移动

流程：

```text
创建目标临时文件 `.mediaflow-part-{operation_id}`
  → 流式复制
  → fsync（可配置）
  → 大小校验
  → 快速/完整哈希校验
  → 原子改名为最终目标
  → 删除源文件
  → 删除空源目录（可选）
```

任一步失败：

- 源文件保留；
- 临时目标可安全删除或标记清理；
- 不生成最终目标；
- 操作记录失败。

### 7.3 复制

与跨设备移动相同，但不删除源。默认验证大小；高安全模式验证完整哈希。

### 7.4 硬链接

1. 检查源为常规文件；
2. 目标不存在；
3. `st_dev` 相同；
4. 创建硬链接；
5. 比较 inode/device 或文件 ID；
6. 记录成功。

硬链接不会复制文件内容，磁盘空间预检仅考虑目录元数据，但仍需验证文件系统支持。

### 7.5 符号链接

默认 P1。目标链接内容建议使用绝对容器路径；部署文档必须提示 Emby 容器也需要看到相同路径。若 Emby 与 MediaFlow 挂载路径不一致，符号链接可能失效。

### 7.6 目录创建

`mkdir` 可幂等。只删除由本计划创建且确认为空的目录。

## 8. 字幕和附属文件顺序

默认：

1. 创建目录；
2. 视频；
3. 字幕；
4. NFO 和图片；
5. 其他已确认附属文件；
6. 清理空目录。

若视频失败，不继续处理该视频关联的字幕；其他独立剧集可按配置继续或整体停止。MVP 默认“同任务遇到首个文件失败后停止后续操作”，降低部分成功复杂度。

## 9. 冲突类型

| 冲突 | 行为 |
|---|---|
| 目标存在 | `CONFLICT` |
| 多个源映射到同一目标 | 计划无效 |
| 大小写/Unicode 冲突 | 计划无效 |
| 源快照变化 | 计划过期 |
| 目标目录不可写 | 计划无效 |
| 空间不足 | 计划无效 |
| 硬链接跨设备 | 冲突，可改为 copy |
| 路径过长 | 冲突，可编辑模板 |
| 多版本无命名区分 | `CONFLICT` |

## 10. 冲突策略

MVP 支持：

- `ASK`：默认；
- `SKIP`：跳过当前项，任务可能部分成功；
- `RENAME_WITH_SUFFIX`：由用户确认后附加版本后缀；
- `COMPARE`：比较判断是否重复。

MVP 不支持自动 `OVERWRITE`。

## 11. 重复文件比较

```text
大小不同 → 不同文件
大小相同 → quick hash
quick hash 不同 → 不同文件
quick hash 相同 → 可选 full hash
full hash 相同 → 内容重复
```

快速哈希建议：文件大小 + 前后各固定块 SHA-256。它用于筛查，不作为强一致校验。

## 12. 回滚

### 12.1 可回滚条件

- OperationRecord 成功；
- 目标存在且未改变；
- 原路径未被其他文件占用；
- 当前任务没有被后续任务依赖；
- 用户有权限。

### 12.2 逆操作

| 原操作 | 回滚 |
|---|---|
| rename/move | 目标移动回源 |
| copy | 删除目标副本 |
| hardlink | 删除目标目录项 |
| symlink | 删除链接 |
| mkdir | 仅当为空且由计划创建时删除 |

### 12.3 回滚顺序

严格按成功操作 sequence 逆序。先回滚字幕和附属文件，再回滚视频，最后删除目录。

### 12.4 回滚校验

删除目标前：

- 大小一致；
- verification 值一致；
- mtime 改变时提高警告；
- `force=false` 时任何差异立即停止。

### 12.5 回滚部分失败

任务进入 `ROLLBACK_FAILED`，保留已完成和未完成列表。不得尝试把已回滚项再次正向执行。

## 13. 恢复对账矩阵

### move/rename

| 源 | 目标 | 结论 |
|---|---|---|
| 存在 | 不存在 | 未执行 |
| 不存在 | 存在且校验一致 | 已成功 |
| 存在 | 存在 | 不确定，人工处理 |
| 不存在 | 不存在 | 丢失风险，人工处理 |

### copy

| 源 | 目标 | 结论 |
|---|---|---|
| 存在 | 不存在 | 未执行 |
| 存在 | 存在且校验一致 | 已成功 |
| 存在 | 存在但不一致 | 失败/冲突 |
| 不存在 | 任意 | 异常，人工处理 |

### hardlink

源目标都存在且 device/inode 一致则成功；否则不确定或冲突。

## 14. 测试强制项

- 跨设备移动中途断电模拟；
- 目标临时文件存在；
- 复制完成但数据库未更新；
- 数据库记录成功但目标被外部删除；
- 大小写冲突；
- Unicode 规范冲突；
- 权限变化；
- 空间不足；
- 硬链接跨设备；
- 回滚时原路径被占用；
- 符号链接逃逸授权根。
