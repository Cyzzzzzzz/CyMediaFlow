# MediaFlow 前端产品与交互规格

> 文档编号：MF-FE-001  
> 技术建议：React + TypeScript + Vite

## 1. 信息架构

```text
/login
/
/tasks
/tasks/pending
/tasks/:taskId
/scans
/watch-directories
/libraries
/parser-rules
/parser-rules/test
/bindings
/episode-mappings
/integrations
/settings
/logs
/system
```

## 2. 全局布局

### 2.1 左侧导航

- 仪表盘；
- 待确认；
- 全部任务；
- 扫描记录；
- 监听目录；
- 媒体库；
- 解析规则；
- 目录绑定；
- 集数映射；
- 集成；
- 日志；
- 系统设置。

待确认和失败任务在导航上显示数量徽标。

### 2.2 顶栏

- 全局搜索；
- 当前后台任务；
- Emby/Provider 状态；
- 用户菜单；
- 版本更新提示（后续）。

## 3. 视觉与交互原则

- 桌面优先，适配 1280px 以上 NAS 管理场景；
- 文件路径使用等宽字体并支持复制；
- 状态颜色不是唯一信息，必须有文字和图标；
- 危险按钮不作为默认主按钮；
- “执行”和“回滚”必须弹出摘要确认；
- 表格支持紧凑模式；
- 大列表服务端分页；
- 路径过长中间省略，悬停显示完整内容。

## 4. 登录页

字段：用户名、密码。  
行为：

- 登录失败显示通用错误，不区分用户不存在和密码错误；
- 首次登录提示修改初始化密码；
- 显示后端连接失败和版本不兼容。

## 5. 仪表盘

### 5.1 指标卡

- 待确认；
- 冲突；
- 执行中；
- 今日成功；
- 今日失败；
- Emby 刷新失败。

### 5.2 区块

- 最近任务时间线；
- 最近错误；
- 监听目录最近扫描；
- 集成健康状态；
- 各媒体库剩余空间；
- 任务状态分布。

所有卡片点击进入带过滤条件的列表。

## 6. 任务列表

### 6.1 列

| 列 | 说明 |
|---|---|
| 状态 | 图标、状态文字、原因 |
| 标题 | 解析标题/确认标题 |
| 来源 | 源目录 |
| 类型 | 电影/电视剧/动画 |
| 文件 | 视频和字幕数量 |
| 匹配 | Provider 和得分 |
| 目标 | 媒体库 |
| 更新时间 | 最近变化 |
| 操作 | 查看、确认、重试 |

### 6.2 过滤

- 多选状态；
- 媒体类型；
- 监听目录；
- 目标媒体库；
- 确认原因；
- 时间范围；
- 关键词。

过滤状态同步到 URL，便于刷新和分享本地链接。

### 6.3 批量操作

P1 支持批量重新搜索、设置媒体库、生成计划。批量执行必须逐任务展示风险，不提供“无确认全执行”。

## 7. 待确认工作台

适用于 `WAITING_CONFIRMATION`、`CONFLICT`、`RECOVERY_REQUIRED`。

左侧：任务队列。  
中间：当前任务编辑区域。  
右侧：原始文件和解析 Trace。

确认原因分区：

- 条目歧义；
- 标题或集数缺失；
- 特别篇映射；
- 字幕关联；
- 文件冲突；
- 恢复对账。

## 8. 任务详情页

采用步骤页签：

1. 概览；
2. 文件与解析；
3. 元数据；
4. 季集映射；
5. 操作预览；
6. 执行记录；
7. 日志。

### 8.1 概览

- 当前状态和可执行动作；
- 进度；
- 来源/目标；
- 条目；
- 最近错误；
- 时间线。

### 8.2 文件与解析

表格列：

- 文件角色；
- 原始文件名；
- 标题；
- 季/集/绝对集；
- 字幕语言；
- 发布组；
- 技术标签；
- 置信度；
- 警告。

点击文件展开解析 Trace。

### 8.3 元数据候选

候选卡展示：

- 海报；
- 标题与原始标题；
- 年份；
- 类型；
- 集数；
- Provider；
- 总分和评分明细；
- 简介；
- 选择按钮。

第一名不满足自动阈值时显示明确原因，如“与第二名只相差 3 分”。

### 8.4 季集映射编辑器

表格：

| 源文件 | 原编号 | 目标季 | 目标集 | 类型 | 冲突 |
|---|---|---:|---:|---|---|

功能：

- 设置起始季和起始集；
- 自动顺序填充；
- Season 00 特别篇；
- 单项覆盖；
- 映射冲突高亮；
- 保存为该作品长期规则。

### 8.5 操作预览

树状或表格显示：

```text
/inbox/.../old.mkv
  → /media/anime/龙珠 (1986)/Season 01/龙珠 S01E01.mkv
```

列：源、目标、操作、大小、预检、冲突。  
突出：

- 会删除源的 move；
- 会额外占用空间的 copy；
- 硬链接跨设备；
- 目标已存在；
- 无字幕语言；
- 未识别附属文件。

执行确认弹窗显示：文件数、总大小、源删除数量、冲突决策、是否刷新 Emby。

### 8.6 执行记录

每项显示：

- 操作序号；
- 开始/完成时间；
- 源和目标；
- 校验方式；
- 状态；
- 错误；
- 回滚状态。

## 9. 扫描记录页

展示扫描批次、触发方式、目录、观察文件、创建任务、耗时和错误。支持取消正在遍历的扫描和跳转相关任务。

## 10. 监听目录页

表单：

- 名称；
- 容器路径；
- 媒体类型；
- 目标媒体库；
- 递归；
- 扫描周期；
- 稳定时间；
- 操作模式；
- 自动匹配；
- 自动执行；
- 忽略规则。

保存前“测试目录”显示可读、设备、样例文件和危险嵌套警告。

## 11. 媒体库页

表单：

- 类型；
- 根路径；
- 目录模板；
- 文件模板；
- 字幕标签风格；
- 标题语言优先级；
- 冲突策略。

提供模板实时预览，使用固定龙珠/电影/电视剧样例和用户自定义样例。

## 12. 解析规则页

列表显示优先级、范围、命中次数、最近失败、状态。编辑器包括：

- 正则；
- 命名捕获组映射；
- 适用媒体类型；
- 发布组；
- 目录范围；
- stop_on_match；
- 测试样例。

规则测试显示逐步 Trace，不能只显示最终 JSON。

## 13. 目录绑定和映射页

目录绑定列表可查看源目录、作品、目标库、标题覆盖和映射。删除绑定只影响未来任务。

集数映射页提供区间和显式映射编辑，保存前运行：

- 区间重叠；
- 目标冲突；
- 负数/零集；
- Season 00 特别篇重复。

## 14. 集成页

卡片：TMDB、Bangumi、Emby。

每张卡：

- 启用开关；
- 配置状态；
- 测试连接；
- 最近成功；
- 最近错误；
- 能力列表。

Token 输入保存后清空，不回填明文。

Emby 额外显示服务器名称、版本、媒体库和刷新队列。

## 15. 系统设置

分组：

- 基础；
- 扫描；
- 任务与并发；
- 命名；
- 字幕；
- 文件校验；
- 日志；
- 安全；
- 备份。

设置页根据 `/settings/schema` 动态展示默认值和风险说明。

## 16. 前端状态管理

- TanStack Query：服务端状态；
- Zustand：页面临时编辑、筛选偏好和未保存表单；
- 不把 Token 存入 localStorage；
- 任务事件通过 SSE 更新 Query Cache；
- 编辑器保存前基于资源版本做乐观锁。

## 17. 错误呈现

错误由 `error.code` 映射到本地化文案，同时展示可操作建议。例如：

```text
TARGET_FILE_EXISTS
目标文件已存在。请比较文件、修改模板或跳过该项。
```

系统错误可复制 request ID。默认不向用户展示后端堆栈。

## 18. 可访问性

- 所有表单有 label；
- 键盘可访问；
- 状态不只依赖颜色；
- 确认弹窗焦点管理；
- 图片提供标题 alt；
- 路径复制按钮有可读名称；
- 表格在窄屏可横向滚动。

## 19. 前端测试

- 组件：状态徽标、路径 Diff、模板预览、候选卡；
- 页面：任务确认和冲突处理；
- Mock API：各种任务状态；
- E2E：龙珠任务从待确认到执行成功；
- E2E：目标冲突不得显示直接执行；
- E2E：Emby 失败时文件成功状态保持。
